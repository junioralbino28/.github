# Padrão dos projetos desta conta

Este repositório guarda o que vale para todos os projetos públicos da conta.

- **Formulários de issue** ("Relatar um erro" e "Sugestão") em `.github/ISSUE_TEMPLATE`. O GitHub usa estes formulários em todo repositório da conta que não tiver formulários próprios.
- **Como ajudar** (`CONTRIBUTING.md`) e **ajuda** (`SUPPORT.md`), que também valem para todos os repositórios.
- **Modelos** em `modelos/`, para copiar em cada projeto:
  - `README-ajude.md`: a seção "Gostou? Ajude o …" do fim do README;
  - `AGENTS.md`: o guia para o assistente de IA de quem baixa o projeto;
  - `BOTOES.md`: os botões de estrela, erro e sugestão dentro do app.

A regra que vale para todos: pedir retorno de forma aberta. Nada de instrução escondida para a IA de alguém agir sozinha.
