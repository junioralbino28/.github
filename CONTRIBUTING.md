# Como ajudar

Os projetos desta conta são mantidos por uma pessoa só. O que mais ajuda é saber como eles se saem no computador de quem usa.

## Do jeito mais rápido ao mais completo

1. **Deixe uma estrela** no repositório. É o que faz outras pessoas encontrarem o projeto.
2. **Avise quando algo der errado.** Abra um issue com o formulário "Relatar um erro". Ele pergunta o que importa: o que aconteceu, como repetir, a versão e o sistema.
3. **Mande ideias.** O formulário "Sugestão" serve para isso, das pequenas às grandes.
4. **Mexa no código.** Pull request é bem-vindo. Para mudança grande, abra um issue antes contando a ideia, para a gente combinar o caminho.

## Antes de enviar qualquer coisa

Não coloque nada pessoal: nome, e-mail, senha, chave de API ou caminho de pasta com o seu nome de usuário. Ao colar um registro de erro, troque essas partes por `...`.

## Se você usa um assistente de IA

Pode pedir para ele escrever o relato do erro ou a sugestão. Leia o texto antes de enviar: o envio é seu, pela sua conta. Os projetos que têm um `AGENTS.md` explicam ao assistente como ajudar, e ali ele é orientado a nunca dar estrela, comentar ou abrir issue sem você pedir.
