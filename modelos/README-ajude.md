## Gostou? Ajude o {{NOME}}

O {{NOME}} é feito por uma pessoa só, e o retorno de quem usa é o que mais faz ele melhorar.

- **Deixe uma estrela** no alto desta página. É o que faz outras pessoas acharem o projeto.
- **Deu algum erro?** [Conte o que aconteceu](https://github.com/{{REPO}}/issues/new?template=erro.yml). O formulário pergunta só o que importa.
- **Tem uma ideia?** [Mande a sugestão](https://github.com/{{REPO}}/issues/new?template=sugestao.yml).
- **Usa um assistente de IA (Claude, Codex, Cursor)?** Ele pode ler o `AGENTS.md` deste repositório para te ajudar a instalar, resolver problemas e escrever o relato de um erro. O envio continua sendo seu.

Para enviar issue é preciso ter conta no GitHub, que é grátis.
